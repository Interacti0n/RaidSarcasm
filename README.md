# RaidSarcasm

**RaidSarcasm** is a World of Warcraft addon that provides sarcastic raid emotes for calling out questionable gameplay in a humorous way.

The addon lets you quickly send a random sarcastic emote aimed at your current target. Each category contains multiple messages, so the same button can produce a different response every time.

## Features

* 🎯 Automatically targets your current target
* 🎲 Random emote selection
* 💬 Sends messages as raid emotes
* 🛡️ Lost Tank messages
* ⚔️ Low DPS messages
* 🧱 No Threat messages
* 🖥️ Simple movable GUI
* 🎨 ElvUI button styling support
* ⌨️ Slash commands for quick access

## Slash Commands

| Command     | Description                   |
| ----------- | ----------------------------- |
| `/losttank` | Send a random Lost Tank emote |
| `/badplay`  | Send a random Low DPS emote   |
| `/nothreat` | Send a random No Threat emote |
| `/rsmenu`   | Toggle the RaidSarcasm menu   |

## Current Categories

### Lost Tank

Sarcastic messages for tanks who seem to have lost their way.

### Low DPS

For DPS players whose damage output could use some encouragement.

### No Threat

For tanks generating approximately as much threat as a decorative shield.

## Development

RaidSarcasm is currently a **work in progress**. More categories, emotes, and improvements are planned as the addon evolves.

The project is intentionally kept simple and modular so that new emotes and categories can be added easily.

## Compatibility

* World of Warcraft: Mists of Pandaria — Patch 5.4.8
* ElvUI: Optional
